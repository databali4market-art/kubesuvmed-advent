# Sem nahrajte nové fotky

Původní fotky (JPG/PNG, klidně velké) nahrajte do této složky – Claude je převede do WebP, ořeže a umístí na web.
Tahle složka se na web nenasazuje.

Pojmenujte je prosím podle místa (nebo napište do chatu, co kam patří).

Hotovo 24. 11.: úvodní koláž, 1. 12. přípitek, „Od včel až pod stromeček“ (včelaři, plástev, úly) a „Darujte něco dobrého“ (louka, zimní set, dobroty, degustační set).
